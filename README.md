# Cologne ticket watch

Checks the public ESL announcement card for Wave 2 / 1-Day Lower and notifies the owner in Telegram.

Scheduled every five minutes via GitHub Actions; runs may be delayed. Status reports after 09:00, 15:00 and 21:00 Europe/Berlin. No purchases or checkout inventory checks. Secrets are stored only in GitHub Actions secrets.

Standard public-repository runners are free. Scheduled workflows can be disabled after 60 days of repository inactivity. Check the Actions tab periodically.
